# 🚀 AI-Powered Career Guidance & Skill Recommendation Agent

## 📌 Project Overview

The AI-Powered Career Guidance Agent is an intelligent recommendation system that analyzes a user’s skills and suggests suitable career paths based on similarity matching using Machine Learning techniques.

This project performs:
- Career Matching
- Skill Gap Analysis
- Match Score Calculation
- Top 3 Career Recommendations

---

## 🧠 Technologies Used

- Python
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity
- Streamlit (Frontend)
- Pandas

---

## 📊 How It Works

1. User enters their skills.
2. Skills are converted into TF-IDF vectors.
3. Cosine similarity is calculated between user skills and career skill sets.
4. Top 3 careers are recommended.
5. Missing skills are displayed for improvement.
